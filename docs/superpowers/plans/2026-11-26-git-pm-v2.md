# git-pm v2 迭代 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（本流程已确立）。步骤用 `- [ ]` 复选框。

**Goal:** 在已完成的 git-pm v1 基础上迭代：主题切换、独立密码生成器、切换提速、更大启动窗口、耗时操作进度条、中央文件浏览器。

**Architecture:** 延续 v1：领域模块（不依赖 egui）+ app.rs UI。新增 `src/browser.rs` 纯文件系统列表模块；git 查询从 UI 线程同步调用改为 `std::thread` 后台执行 + 每项目缓存；菜单栏承载主题切换与工具入口。

**Tech Stack:** 不新增依赖（egui 0.28 自带 visuals/菜单/进度条；fs 元数据用 std）。

**Spec:** 用户 6 点需求（对话给定）：1) 界面风格可切换（暗黑/明亮）；2) 独立密码生成功能以菜单项实现；3) 项目间切换延时优化；4) 启动窗口更大、所有面板可见；5) 耗时操作加进度条；6) 选中项目后中央多栏文件浏览器（文件/目录、大小等）。

## Global Constraints

- 沿用 v1 全部约束：gitpm.db 在程序当前目录；git 仅经 CLI；加密体系不变；领域模块不依赖 egui；错误 match 显示不 panic。
- 裁定：主题默认暗黑、选择持久化到 meta 表（key=`theme`，b"dark"/b"light"）；文件浏览器 `.git` 目录显示但置灰、文件只读（双击不打开）；进度条为动态不确定进度（git CLI 无真实进度）；git 查询后台线程 + 按项目缓存（缓存键 project_id，操作后失效重取）。
- release 保持无控制台（已有 windows_subsystem）；中文字体加载逻辑不动。

## Review Focus

1. **后台线程与 UI 状态竞态** — git 结果回填时项目可能已切换；结果必须携带 project_id，回填前校验仍选中才更新缓存/显示。→ Task 5 测试（缓存键校验逻辑单元测试）+ 人工验收。
2. **主题持久化在无库/锁定库时不崩溃** — meta 读写失败仅降级为本次会话生效。→ Task 1 测试。
3. **文件浏览器对特殊路径健壮** — 无权限目录、超长文件名、非 UTF-8 文件名不 panic（lossy 显示）。→ Task 3 测试。
4. **独立生成器与凭据对话框互不干扰** — 两处共享 GenOptions 状态但各自独立打开/关闭。→ Task 2 人工验收点。
5. **切换瞬间显示缓存** — 选中立即渲染缓存状态，不等待 git。→ Task 5 人工验收点。

### Task 3: browser.rs 文件列表领域模块

**Files:** Create `src/browser.rs`；Modify `src/main.rs`（mod browser;）
**Interfaces:** Produce:
- `pub struct Entry { pub name: String, pub is_dir: bool, pub size: u64, pub modified: Option<String>, pub is_hidden: bool }`（size 对目录为 0）

- [ ] Step 1: 失败测试：tempdir 建目录+文件断言排序/大小/is_dir/is_hidden；`list_dir` 传入不存在路径 → Err；fmt_size 边界（0、1023、1024、1048576）。
