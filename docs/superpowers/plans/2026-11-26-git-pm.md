# Git 项目管理器（git-pm）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个 Rust + egui 的本地桌面程序，用树形管理多个 git 仓库目录，通过命令行 git 执行常规操作，密码经主密码加密后与项目一起存于本程序目录下的 SQLite 中。

**Architecture:** 单 crate 二进制 `git-pm`。UI 层（egui/eframe）调用领域模块：`db.rs`（rusqlite：项目表、凭据表、主密码元数据表）、`crypto.rs`（Argon2id 派生密钥 + AES-256-GCM 加解密）、`password.rs`（密码生成器）、`git.rs`（`std::process::Command` 调用 git CLI 并捕获输出）。所有 git 操作只走 CLI，不使用 git2/libgit2。

**Tech Stack:** Rust stable (edition 2021)、eframe/egui、rusqlite（bundled）、argon2、aes-gcm、rand、tempfile（dev）。

**Spec:** 用户需求（对话给定）：1) git 操作经命令行 git；2) 本地程序，Rust；3) 项目树形显示、添加/删除（删除仅从树中移除，不动文件系统）；4) 常规操作 commit/pull/push/branch/tag 等；5) 加密保存各仓库密码；6) clone 到指定目录并自动加入项目树；7) 项目与密码数据存于程序当前目录的 SQLite；8) 高强度密码生成：指定位数，默认含大小写字母+数字，可选特殊字符。

## Global Constraints

- 数据库文件固定为程序当前工作目录下的 `gitpm.db`（相对路径，不做绝对路径配置）。
- git 一律通过 `std::process::Command` 调用 PATH 中的 `git`；禁止 git2/libgit2 依赖。
- 加密：Argon2id（m=64MiB, t=3, p=1, 32 字节输出）派生密钥；AES-256-GCM 加密；nonce 每次 12 字节随机。
- 主密码校验用"魔串验证器"：setup 时用派生密钥加密固定魔串存入 meta；unlock 时解密比对。
- 删除项目只删 DB 行（含其凭据行），绝不触碰文件系统目录。
- 同一路径不允许重复添加（projects.path 唯一索引）。
- 平台：Windows 开发环境优先，代码保持可移植；测试需系统已安装 git。
- 所有领域模块不得依赖 egui；UI 层单向调用领域模块。

## Review Focus

按最可能咬人的顺序：

1. **删除项目误删目录** — remove 后文件系统目录必须原样存在。→ Task 2 测试 `remove_keeps_directory`。
2. **错误主密码** — unlock 必须返回错误而非 panic/解出垃圾。→ Task 3 测试 `wrong_master_fails`。
3. **密码生成字符集泄漏** — special=false 时绝无特殊字符；length 必须精确；length 小于所选类数时返回错误。→ Task 5 测试。
4. **git 失败静默** — 非零退出码、git 不存在都必须以 `GitOutput.code != 0` / `io::Error` 显式返回，UI 显示 stderr。→ Task 6 测试 `missing_git_is_error`（PATH 注入空目录）。
5. **重复添加同一路径** — 必须被拒绝并提示。→ Task 2 测试 `duplicate_path_rejected`。

### Task 5: password.rs — 密码生成器

**Files:**
- Create: `src/password.rs`；Modify: `src/main.rs`（`mod password;`）

**Interfaces:**
- Produces:
  - `pub struct GenOptions { pub length: usize, pub upper: bool, pub lower: bool, pub digits: bool, pub special: bool }`
  - `pub fn generate(opts: &GenOptions) -> Result<String, String>`；字符集：upper `A-Z`、lower `a-z`、digits `0-9`、special ``!@#$%^&*()-_=+[]{};:,.<>?``；从所选类各取至少 1 字符（OsRng），余位从所选并集随机，最后整体 Fisher-Yates 洗牌；`length == 0` 或 length < 所选类数 → Err；全类均 false → Err。

  #[test] fn exact_length_small() // length=4, 仅 lower+digits → len==4 且字符均属该并集
